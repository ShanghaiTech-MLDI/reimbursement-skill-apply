# 申请加入：上科大出国报销 Agent Skill

这里是 **上科大学生因公出国报销 skill**（[ShanghaiTech-MLDI/shanghaitech-overseas-reimbursement](https://github.com/ShanghaiTech-MLDI/shanghaitech-overseas-reimbursement)，私有）的申请入口。skill 本身在一个私有仓库里，用来让 AI Agent 带你走完出国开会报销的全流程：盘点材料、算金额、在 OA 和 BPM 里填表。大家用完后一起维护，把新踩的坑写回去。

## 怎么申请

1. 点上面的 **Issues → New issue → 申请加入**，填好表单后提交。不用填邮箱，系统直接用你的 GitHub 账号。
2. 维护者同意后，你会收到 GitHub 的组织邀请邮件，也可以在 https://github.com/orgs/ShanghaiTech-MLDI/invitation 查看。**点「Join」接受**之后就能看到 skill 仓库。邀请 7 天内有效。
3. 按 skill 仓库 README 里的说明安装和使用。

## 注意

- 这个仓库是公开的，**申请里不要写学号、手机号这类个人信息**。
- 加入后你会有 skill 仓库的写权限，请按仓库里的 CONTRIBUTING.md 维护，**不要提交任何真实个人信息**。
